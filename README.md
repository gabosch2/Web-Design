# Web-Design
O Web Design envolve o planejamento, a estruturação e a criação visual de páginas e interfaces para a web, unindo estética, funcionalidade e experiência do usuário por meio de tecnologias como HTML, CSS e JavaScript. Neste repositório, você encontrará os materiais das aulas lecionadas durante o curso, além das atividades e relatórios desenvoplvidos pelo meu grupo (incluindo o projeto EcoEnergia).
